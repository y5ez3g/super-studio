# super-studio

**Turn ideas into products, like a professional studio.**

super-studio has two kinds of agent skills:

- **pm** skills shape your idea into a product design, with you.
- **team** skills build that design into a product.

Today there's one of each: **super-pm** and **super-team**.

## Install

**Claude Code**
```
/plugin marketplace add y5ez3g/super-studio
/plugin install super-studio@super-studio
```

**Codex**
```
codex plugin marketplace add y5ez3g/super-studio
codex plugin add super-studio@super-studio
```

super-team runs in Claude Code and needs the Codex CLI logged in.

## Quick start

In an empty folder in Claude Code:
```
/super-pm <your idea>
```
Answer its questions and pick the design you like. Then:
```
/super-team
```
Set a budget, in hours and review rounds, and let the team build.

## How it works

**super-pm** clarifies the requirements with you, then designs the product. You pick the direction you like.

**super-team** takes the design and your budget, builds the product, then makes it as good as it can within that budget.

## Today

- **super-pm** designs 3D web games.
- **super-team** pairs Claude and Codex: Claude builds, Codex reviews.
